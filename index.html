03 / FAQ

Questions before you start.

Do I need an account?

No. You can start a practice task immediately.

Does the timer start automatically?

No. The timer begins only after you press Start Task.

Is TOEFLPrep official ETS material?

No. TOEFLPrep is an independent practice site and is not affiliated with ETS.

Will more TOEFL tasks be added?

Yes. Complete the Words is the initial focus; the architecture can expand to other task types later.
